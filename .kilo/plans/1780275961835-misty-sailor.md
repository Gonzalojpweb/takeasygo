# Plan: Rename route from /explore to /app

## Objective
Change the public route of the explore page from `/explore` to `/app` while keeping the API routes under `/api/explore` unchanged.

## Steps

1. Rename the directory `app/explore` to `app/app`.
2. Update all references to the old path in the codebase (excluding API routes and internal fetch calls) to the new path.
3. Update configuration files (next.config.ts, manifest.ts, sw.js, etc.)
4. Test the changes.
